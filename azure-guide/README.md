# Azure for Data Engineer Interviews

A static site for preparing for Azure data engineer interviews (about 4 years of experience). It has service pages, 109 interview questions with model answers, design walkthroughs, and comparison tables including an AWS to Azure mapping. It uses the same design as `../aws-guide`, works on laptop and phone, and needs no build step.

## View locally

Open `index.html` in a browser, or run `python3 -m http.server` in this folder.

## Host on GitHub Pages

Push the folder to the repo and enable Pages. Navigation uses `#/page-id` URLs, so no server config is needed. The root `index.html` lists folders that contain an `index.html`, so this guide appears there automatically.
