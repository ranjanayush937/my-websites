dbt Running & Building Models

dbt run

Executes the SQL for your models, creating or replacing tables/views in the target warehouse. The core command of any dbt project.

Real-world example

# Run only the defence combined mart and everything it depends on
dbt run --select +int_rrd_defence_combined

# Run a full refresh of an incremental model after a logic change
dbt run --select rrd_agent_master_defense --full-refresh

# Run against the UAT target before promoting to prod
dbt run --target uat --select staging.*

dbt build

Runs models, tests, snapshots, and seeds together in dependency order. If a model's tests fail, downstream models are skipped — ideal for CI and scheduled jobs.

Real-world example

# Nightly job: build the whole defence pipeline and stop on first failure
dbt build --fail-fast

# Build a single mart plus its upstream, with tests gating each step
dbt build --select +rrd_agent_master_defense

dbt test

Runs data-quality tests (schema tests like unique/not_null and singular SQL tests) against already-built models.

Real-world example

# Validate grain and business rules on the agent base model
dbt test --select int_rrd_defence_agent_base

# Run a specific singular test that checks MTD >= FTD
dbt test --select test_mtd_gte_ftd_nop

# Store failing rows in the warehouse for debugging
dbt test --store-failures --select rrd_agent_master_defense

dbt compile

Renders Jinja/macros into raw SQL under target/ without running it. Great for inspecting exactly what dbt will send to the warehouse.

Real-world example

# See the final SQL for a model to debug a macro
dbt compile --select int_rrd_defence_combined
# then open target/compiled/.../int_rrd_defence_combined.sql

dbt seed

Loads CSV files from the seeds/ directory into the warehouse as tables. Used for small, version-controlled lookup/reference data.

Real-world example

# Load a designation-role mapping CSV into the warehouse
dbt seed --select defence_designation_lookup

# Reload all seeds, replacing existing tables
dbt seed --full-refresh

dbt snapshot

Captures slowly changing dimensions (Type 2 history) by recording how rows change over time.

Real-world example

# Track changes to agent geo-hierarchy assignments over time
dbt snapshot --select defence_agent_hierarchy_snapshot

dbt deps

Installs packages listed in packages.yml (e.g. dbt_utils) into dbt_packages/. Run after cloning or updating dependencies.

Real-world example

# First step after cloning the repo on a new machine
dbt deps

dbt debug

Checks your setup: profile, connection to the warehouse, and project validity. The first thing to run when something won't connect.

Real-world example

# Confirm the UAT connection works before a deployment
dbt debug --target uat

dbt docs generate / dbt docs serve

Builds a browsable documentation site (lineage graph, column descriptions, tests) and serves it locally.

Real-world example

# Generate docs then open the lineage DAG in a browser
dbt docs generate
dbt docs serve --port 8080

dbt ls & selection syntax

Lists resources matching a selector without running them. Handy for verifying what a --select will touch.

Real-world example

# List every model downstream of the staging layer
dbt ls --select staging.*+

# Only models tagged 'defence' that are also marts
dbt ls --select tag:defence,mart.*

# Preview what a scheduled run will execute
dbt ls --select +rrd_agent_master_defense --resource-type model

dbt Project Setup & Utilities

dbt init / dbt clean / dbt parse

dbt init Scaffolds a new dbt project and walks you through creating a connection profile. dbt clean Deletes the folders listed under clean-targets in dbt_project.yml, usually target/ and dbt_packages/. dbt parse Parses the project and writes target/manifest.json without connecting to the warehouse. Quick way to catch YAML and Jinja errors.

Real-world example

# Create a new project in a new folder
dbt init my_project
# Scaffold without touching your existing profiles.yml
dbt init my_project --skip-profile-setup
# Remove compiled artifacts and installed packages
dbt clean
# Start from a clean slate, then reinstall packages
dbt clean && dbt deps
# Validate the project structure and refs
dbt parse
# Ignore the partial-parse cache after changing dbt_project.yml
dbt parse --no-partial-parse

dbt show

Previews the result of a model or an inline query in the terminal without materializing anything.

Real-world example

# Peek at 10 rows from a model
dbt show --select rrd_agent_master_defense --limit 10
# Run an ad-hoc query with ref()
dbt show --inline "select count(*) as n from {{ ref('int_rrd_defence_combined') }}"

dbt retry / dbt clone

dbt retry Re-runs the previous dbt command, starting from the nodes that failed or were skipped (dbt 1.6+). dbt clone Creates copies of nodes from a previous run's state as views or tables in your target schema (dbt 1.6+). Useful for cheap dev environments.

Real-world example

# Resume after a failed build without redoing the successful models
dbt retry
# Clone prod models into your dev schema using saved prod artifacts
dbt clone --state prod-artifacts --select rrd_agent_master_defense

dbt run-operation

Runs a macro directly from the command line, for example to grant permissions or clean up old tables.

Real-world example

# Run a macro with no arguments
dbt run-operation grant_select_on_marts
# Pass arguments to the macro as YAML
dbt run-operation grant_select --args '{role: reporting}'

git Git Version Control

git clone / git init

Copies a remote repository to your machine, or initializes a brand-new repo in the current folder.

Real-world example

# Clone the team's dbt project
git clone git@github.com:acme/seller-app-defence.git

# Start tracking an existing folder with Git
cd my-project && git init

git status / git add

Shows which files changed, and stages specific files for the next commit. Prefer naming files over git add . to avoid committing unrelated changes.

Real-world example

git status

# Stage just the two models you edited
git add models/mart/rrd_agent_master_defense.sql models/mart/schema.yml

git commit

Records staged changes as a snapshot with a message describing the change.

Real-world example

# Commit with a clear, scoped message
git commit -m "fix: correct MTD/FTD grain in defence agent base model"

git branch / git checkout / git switch

Creates, lists, and moves between branches. Branches keep feature work isolated from main.

Real-world example

# Create and switch to a feature branch in one step
git switch -c feature/defence-combined-mart

# List all branches, see the current one
git branch -a

# Go back to main
git switch main

git merge / git rebase

Integrates changes from one branch into another. merge keeps history; rebase replays commits for a linear history.

Real-world example

# Merge a finished feature into main
git switch main && git merge feature/defence-combined-mart

# Rebase your branch onto the latest main before a PR
git switch feature/defence-combined-mart && git rebase main

git push / git pull / git fetch

Syncs commits with the remote. fetch downloads without merging; pull fetches + merges; push uploads your commits.

Real-world example

# Push a new branch and set upstream tracking
git push -u origin feature/defence-combined-mart

# Get the latest main without touching your working copy
git fetch origin

# Update your current branch from the remote
git pull

git log / git diff

Views commit history and inspects exactly what changed between versions or in your working tree.

Real-world example

# Compact, graphical history
git log --oneline --graph --decorate -15

# See unstaged changes to a model
git diff models/mart/rrd_agent_master_defense.sql

# Compare two branches
git diff main..feature/defence-combined-mart

git stash

Temporarily shelves uncommitted changes so you can switch context, then restores them later.

Real-world example

# Stash WIP to quickly fix a bug on main
git stash push -m "wip defence mart"
git switch main
# ...fix...
git switch feature/defence-combined-mart && git stash pop

git reset / git revert

Undoes changes. revert creates a new commit that reverses another (safe for shared branches); reset moves the branch pointer (use with care).

Real-world example

# Safely undo a pushed commit by adding a reversing commit
git revert a1b2c3d

# Unstage a file but keep the edits
git reset HEAD models/mart/schema.yml

# Discard the last commit but keep changes in working tree
git reset --soft HEAD~1

git worktree / git cherry-pick

worktree checks out multiple branches in separate folders at once; cherry-pick copies a single commit onto the current branch.

Real-world example

# Work on a hotfix without disturbing your main checkout
git worktree add ../hotfix-dir -b hotfix/urgent main

# Apply just one commit from another branch
git cherry-pick a1b2c3d

git Inspect & Recover

git show / git blame

git show Displays a commit (message and diff) or a file as it was at a given commit. git blame Shows who last changed each line of a file and in which commit.

Real-world example

# Show the latest commit
git show HEAD
# Summarise files changed in a commit
git show --stat a1b2c3d
# View a file as it was two commits ago
git show HEAD~2:models/mart/schema.yml
# Annotate a whole file
git blame models/mart/rrd_agent_master_defense.sql
# Limit to lines 40-60 and ignore whitespace changes
git blame -w -L 40,60 models/mart/rrd_agent_master_defense.sql

git reflog / git bisect

git reflog Lists where HEAD and branches have pointed recently. Lets you recover commits after a bad reset, rebase or deleted branch. git bisect Binary-searches your history to find the commit that introduced a bug.

Real-world example

# See recent HEAD movements
git reflog
# Recreate a lost branch from a reflog entry
git branch recovered HEAD@{3}
# Start and mark the current commit as broken
git bisect start
git bisect bad
# Mark a known-good commit; Git checks out the midpoint
git bisect good v1.2.0
# Automate the search with a test script
git bisect run ./scripts/check.sh
# Finish and return to your branch
git bisect reset

git Files, Tags, Remotes & Config

git restore / git rm / git mv

git restore Discards working-tree changes or unstages files. Replaces the file-level uses of git checkout and git reset. git rm Removes a file from the working tree and the index. git mv Renames or moves a file and stages the change in one step.

Real-world example

# Discard unstaged edits to a file
git restore models/mart/schema.yml
# Unstage a file but keep the edits
git restore --staged models/mart/schema.yml
# Bring back a file from an earlier commit
git restore --source=HEAD~1 models/mart/schema.yml
# Stop tracking a file but keep it on disk
git rm --cached .env
# Delete a tracked folder
git rm -r old_models/
# Rename a model file
git mv models/staging/stg_agent.sql models/staging/stg_defence_agent.sql

git tag / git remote

git tag Marks a specific commit, usually for a release. git remote Manages the remote repositories your clone talks to.

Real-world example

# Create an annotated tag
git tag -a v1.4.0 -m "Release 1.4.0"
# List tags
git tag -l "v1.*"
# Push one tag to the remote
git push origin v1.4.0
# Delete a tag locally
git tag -d v1.4.0
# Show remotes and their URLs
git remote -v
# Add a second remote called upstream
git remote add upstream git@github.com:acme/seller-app-defence.git
# Change the URL of origin
git remote set-url origin git@github.com:acme/new-name.git
# Drop local references to branches deleted on the remote
git remote prune origin

git config / git clean

git config Reads and sets Git options at the repo, user (--global) or system level. git clean Deletes untracked files. Deleted files cannot be recovered, so preview first.

Real-world example

# Set your identity
git config --global user.name "Your Name"
git config --global user.email you@example.com
# Create a shortcut
git config --global alias.st status
# See every setting and the file it came from
git config --list --show-origin
# Dry run: list what would be removed
git clean -n -d
# Remove untracked files and folders
git clean -fd

linux Navigation

pwd / cd / ls

Print the current directory, change directories, and list contents.

Real-world example

pwd                      # where am I?
cd dbt/defence_agent_master
ls -lah                  # long listing, human sizes, including hidden files
cd -                     # jump back to the previous directory

linux Files & Directories

mkdir / cp / mv / rm / touch

Create, copy, move/rename, delete files and folders.

Real-world example

mkdir -p models/intermediate      # create nested dirs, no error if exists
cp profiles.yml profiles.yml.bak  # back up before editing
mv old_model.sql staging/stg_model.sql
touch models/new_model.sql        # create an empty file
rm -i target/*.log                # delete with confirmation prompt
rm -rf target/                    # remove a dir tree (double-check the path!)

linux Viewing Text

cat / less / head / tail

Print, page through, or peek at the start/end of files. tail -f follows a growing log.

Real-world example

cat dbt_project.yml
less target/compiled/.../model.sql     # q to quit
head -20 docs/SOURCE\ DDL.txt
tail -f logs/dbt.log                    # live-follow a running dbt job

linux Searching

grep / find

grep searches file contents; find locates files by name, type, or age.

Real-world example

# Find every model that references a source table
grep -rn "rrd_defence_agents" models/

# Find all SQL files modified in the last day
find models/ -name "*.sql" -mtime -1

# Find and delete compiled artifacts
find target/ -name "*.sql" -delete

linux Permissions & Ownership

chmod / chown

Change file permissions and ownership. Common when a deployment script needs to be executable.

Real-world example

# Make the deployment script executable
chmod +x defence_agent_master_deployement.sh

# Give the service account ownership of the logs dir
sudo chown -R dbtuser:dbtuser /opt/dbt/logs

linux Processes

ps / top / kill / & / nohup

Inspect running processes, monitor resource usage, and stop or background jobs.

Real-world example

# Find a stuck dbt process
ps aux | grep dbt

# Kill it by PID
kill -9 48213

# Run a long dbt build in the background, surviving logout
nohup dbt build --target prod > run.log 2>&1 &

linux Networking

curl / wget / ssh / ping

Make HTTP requests, download files, connect to remote servers, and test connectivity.

Real-world example

# Test a warehouse/API endpoint is reachable
curl -I https://my-warehouse.example.com

# SSH into the deployment server
ssh dbtuser@etl-prod-01

# Download a file
wget https://example.com/reference-data.csv

linux Archives & Transfer

tar / gzip / scp / rsync

Bundle/compress files and move them between machines efficiently.

Real-world example

# Archive and compress the project for backup
tar -czf defence_backup.tar.gz dbt/defence_agent_master

# Copy artifacts to a remote host
scp defence_backup.tar.gz dbtuser@etl-prod-01:/backups/

# Mirror a folder to the server, only sending changes
rsync -avz --delete ./target/ dbtuser@etl-prod-01:/opt/dbt/target/

linux Disk & System

df / du / free / env / export

Check disk space, directory sizes, memory, and manage environment variables.

Real-world example

df -h                     # free space per mounted filesystem
du -sh target/            # how big is the compiled output?
free -h                   # available RAM

# Set an env var a dbt profile reads (e.g. a password)
export DBT_PWD='••••••'
env | grep DBT            # confirm it's set

linux Editing Text

nano / vim

Edit files directly in the terminal. nano is beginner-friendly (shortcuts shown at the bottom); vim is powerful and modal, found on nearly every server.

Real-world example

# Open (or create) a file in nano, then Ctrl+O to save, Ctrl+X to quit
nano models/mart/schema.yml

# Jump straight to line 42 in nano
nano +42 logs/dbt.log

# Open a file in vim; press i to insert, Esc then :wq to save & quit
vim profiles.yml

# Edit a file as root when you forgot sudo
sudo nano /etc/hosts

linux Text Processing

sed / awk / cut / sort / uniq / wc

The classic pipeline toolkit for transforming, slicing, and counting text and CSV data.

Real-world example

# Replace a schema name across a file (in-place, with a .bak backup)
sed -i.bak 's/old_schema/new_schema/g' models/sources.yml

# Print the 2nd comma-separated column of a CSV
awk -F',' '{print $2}' seeds/agents.csv

# Pull columns 1 and 3 from a tab-separated file
cut -f1,3 export.tsv

# Sort rows, drop duplicates, and count how many remain
sort agents.csv | uniq | wc -l

# Count lines in every SQL model
wc -l models/**/*.sql

linux Shell Helpers

man / which / history / ln / xargs

Everyday shell conveniences: read docs, locate binaries, reuse past commands, link files, and feed arguments into other commands.

Real-world example

# Read the manual for a command (q to quit)
man rsync

# Find which binary runs when you type 'dbt'
which dbt

# Re-run a previous command by its history number
history | grep "dbt run"
!512

# Create a symlink to a shared profiles file
ln -s /opt/dbt/profiles.yml ~/.dbt/profiles.yml

# Delete every .log file found, passing them to rm in batches
find . -name "*.log" | xargs rm -f

linux System & Services

sudo / whoami / uname / uptime / date

sudo Runs a command with another user's privileges, normally root. whoami / uname / uptime / date Quick facts about the current user, OS, machine load and time.

Real-world example

# Run one command as root
sudo apt update
# Run as a different user
sudo -u postgres psql
# Re-run the previous command as root
sudo !!
# Current user
whoami
# Kernel and architecture
uname -a
# How long the machine has been up, and load average
uptime
# ISO date for filenames
date +%F

systemctl / journalctl

systemctl Starts, stops and inspects services on systems that use systemd. journalctl Reads logs collected by systemd.

Real-world example

# Check a service
systemctl status nginx
# Restart it
sudo systemctl restart nginx
# Start now and on every boot
sudo systemctl enable --now nginx
# Logs for one service from the last hour
journalctl -u nginx --since "1 hour ago"
# Follow logs live
journalctl -u nginx -f
# Only errors from the current boot
journalctl -p err -b

crontab

Schedules commands to run at fixed times.

Real-world example

# List your jobs
crontab -l
# Edit your jobs
crontab -e
# Example entry: nightly build at 02:00, logging output
0 2 * * * cd /opt/dbt && dbt build >> /var/log/dbt_nightly.log 2>&1

lsof / ss / watch

lsof Lists open files, including network sockets, and the process that owns each. ss Shows network sockets. Modern replacement for netstat on Linux. watch Re-runs a command every few seconds and shows the output. Not installed by default on macOS.

Real-world example

# Which process is using port 8080?
lsof -i :8080
# Files opened by a given process
lsof -p 1234
# Listening TCP/UDP ports with process names
sudo ss -tulpn
# Watch free disk space every 5 seconds
watch -n 5 df -h

linux Everyday Utilities

tree / stat

tree Prints a directory as an indented tree. Install with brew or apt if missing. stat Shows detailed file info: size, permissions, owner, timestamps.

Real-world example

# Two levels deep
tree -L 2
# Skip noisy folders
tree -I "target|dbt_packages|.git"
# Full details
stat run.sh
# Octal permissions and owner (Linux)
stat -c '%a %U' run.sh

diff / tee

diff Compares two files or folders line by line. tee Copies input to both the screen and a file.

Real-world example

# Unified diff of two files
diff -u old.sql new.sql
# List files that differ between two folders
diff -rq models_old/ models/
# Watch a build and save the log
dbt build 2>&1 | tee build.log
# Append to a root-owned file
echo "10.0.0.5 db.internal" | sudo tee -a /etc/hosts

jq

Parses and filters JSON on the command line.

Real-world example

# Pretty-print a JSON file
jq . target/run_results.json
# List dbt nodes that errored
jq -r '.results[] | select(.status=="error") | .unique_id' target/run_results.json

zip / unzip

Creates and extracts .zip archives, which Windows users can open directly.

Real-world example

# Zip a folder
zip -r backup.zip models/
# List contents without extracting
unzip -l backup.zip
# Extract into a folder
unzip backup.zip -d restore/

alias / dig

alias Defines a shortcut for a longer command. Add it to ~/.zshrc or ~/.bashrc to keep it. dig Queries DNS records.

Real-world example

# Shortcut for a detailed listing
alias ll='ls -lah'
# Shortcut for git status
alias gs='git status'
# Remove an alias
unalias gs
# Just the IP address
dig example.com +short
# Mail servers
dig MX example.com
